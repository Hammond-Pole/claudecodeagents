# React Feature Builder Skill

Build, enhance, and fix React frontend features following established architectural patterns with comprehensive testing.

## 📦 What's Included

### SKILL.md (75KB)
The main skill file that guides you through the complete React feature development lifecycle.

### Frontend-Pattern-Guide.md (Bundled Context)
Comprehensive guide to the Hammond Pole Operations Platform's frontend architecture patterns. This file provides:
- Feature-based folder structure
- RTK Query API integration patterns
- State management patterns (server state + URL state)
- Component architecture patterns
- Testing patterns (Vitest + Playwright)
- Accessibility patterns (WCAG AA compliance)
- Theme system patterns (light + dark modes)
- Responsive design patterns

**Note:** If your project already has `ProjectArchitecture/Frontend-Pattern-Guide.md`, the skill will use that version. Otherwise, it will copy this bundled version to your project.

## 🎯 How It Works

### Phase -1: Project Architecture Setup
The skill automatically:
1. Checks if `ProjectArchitecture/` exists in your project
2. Creates the directory structure if needed:
   - `ProjectArchitecture/Plans/` - Implementation plans
   - `ProjectArchitecture/FinalisedBackEndReports/` - Backend API reports (from DDD skill)
   - `ProjectArchitecture/FinalisedFrontEndReports/` - Frontend reports
3. Copies the bundled Frontend-Pattern-Guide.md if not present
4. Checks for backend API reports (generated by ddd-feature-builder)
5. Verifies the structure is ready

### Complete Workflow
1. **Mode Detection** - CREATE / ENHANCE / FIX
2. **Discovery** - 15 comprehensive questions including UI/UX details
3. **Backend Report Loading** - Loads existing backend API reports
4. **Plan Creation** - Saved to `ProjectArchitecture/Plans/`
5. **Plan Approval** - User must approve before coding
6. **TDD Implementation** - Component tests FIRST → Implementation → Refactor
7. **Accessibility Testing** - WCAG AA compliance verification
8. **Theme Testing** - Light + Dark mode validation
9. **Playwright Live Validation** - Manual UI testing with browser
10. **Final Report** - Saved to `ProjectArchitecture/FinalisedFrontEndReports/`

## 🏗️ Output Structure

### Feature Structure Created
```
src/features/[feature-name]/
├── api/
│   └── [feature]Api.ts              # RTK Query endpoints
├── components/
│   ├── [Feature]Page.tsx            # Main page component
│   ├── [Feature]ListView.tsx        # List/table view
│   ├── Create[Feature]Modal.tsx     # Create form
│   ├── Edit[Feature]Modal.tsx       # Edit modal
│   └── __tests__/                   # Component tests
├── hooks/
│   └── use[Feature].ts              # Feature-specific hooks
└── types/
    └── [feature].types.ts           # TypeScript interfaces
```

### Tests Created
- Component unit tests (Vitest + Testing Library)
- E2E tests (Playwright)
- Accessibility tests (jest-axe)

### Additional Outputs
- Feature README
- Final frontend report with screenshots
